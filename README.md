# The Observational Asymmetry Hypothesis (OAH)

Foundational framework on decisional states, observational asymmetry, and verifiable decision architectures.

## Core proposition

"Execution does not imply observability."

OAH proposes that systems become structurally unverifiable when the only mechanism available for reconstructing a decisional state is the same mechanism that produced it.

## Core distinction

State ≠ Access to State

Producing an output does not imply preserving evidence regarding the conditions that generated that output.
