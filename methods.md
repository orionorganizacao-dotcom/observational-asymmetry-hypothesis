# OAH Methods

## Objective

Evaluate whether observational asymmetry produces a gap between reconstruction and independent verification.

## Methodological Structure

1. Define decisional state.

2. Define observation channel.

3. Define reconstruction mechanism.

4. Define independent verification layer.

5. Compare:

- Reconstruction capability
- Verification capability

## Expected Outcomes

Case A:

Reconstruction ≈ Verification

Interpretation:

Low observational asymmetry.

---

Case B:

Reconstruction > Verification

Interpretation:

Moderate observational asymmetry.

---

Case C:

Reconstruction exists while independent verification collapses.

Interpretation:

High observational asymmetry.
