# OAH Limitations

## Scope

The Observational Asymmetry Hypothesis (OAH) does not claim:

- That all decisions can be externally reconstructed.
- That verification guarantees truth.
- That independent evidence guarantees correctness.
- That all systems can preserve pre-decisional states.

## Architectural Limits

OAH may fail when:

1. No independent evidence channel exists.

2. Observation itself irreversibly changes the decisional state.

3. Complete authority concentration prevents external verification.

4. Total collusion exists between all verification layers.

## Interpretation

Failure under these conditions does not falsify OAH.

Instead, these conditions define the boundaries within which OAH operates.
