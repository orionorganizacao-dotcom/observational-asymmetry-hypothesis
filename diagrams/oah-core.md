# OAH Core Architecture

Conventional systems:

Decisional State
      ↓
Output
      ↓
Explanation
      ↓
Audit

Problem:

Output becomes the only surviving evidence.

--------------------------------------------

OAH architecture:

Decisional State
      ↓
Pre-Decisional Commitment
      ↓
Output
      ↓
Independent Verification

Property:

Execution ≠ Observability
