# OAH Experiment 001 — Reconstruction vs Verification

## Research Question

Can independent observers reconstruct a decisional state without preserved pre-decisional evidence?

## Hypothesis

Outputs without preserved commitments generate plausible narratives but not verifiable reconstruction.

## Systems

System A:
Output only

System B:
Output + explanation

System C:
Output + explanation + pre-decisional commitment

## Evaluation Variables

V1 — Confidence score
V2 — Reconstruction consistency
V3 — Verifiability score

## Expected Result

A:
Low confidence

B:
High confidence / low verifiability

C:
High confidence / high verifiability

## Potential falsification

If B performs equivalently to C across independent evaluators, OAH weakens.
