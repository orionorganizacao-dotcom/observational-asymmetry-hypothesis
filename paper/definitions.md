# Definitions

## D1 — Decisional State

A decisional state is the internal informational configuration of a system immediately preceding an executed action.

## D2 — Execution

Execution is the transition from an internal decisional state into an observable output or action.

## D3 — Observation

Observation is any process attempting to access, reconstruct, or infer properties of a decisional state.

## D4 — Observational Accessibility

Observational accessibility represents the degree to which an internal decisional state can be externally reconstructed.

## D5 — Observational Asymmetry

Observational asymmetry exists when producing a state and reconstructing that state have fundamentally different informational requirements.
